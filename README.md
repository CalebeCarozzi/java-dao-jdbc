# Java DAO JDBC

Projeto desenvolvido para praticar acesso a banco de dados em Java utilizando JDBC e o padrão DAO (Data Access Object).

A aplicação trabalha com as entidades `Seller` e `Department`, separando a lógica de acesso a dados por meio de interfaces DAO e implementações JDBC.

## Conceitos praticados

- JDBC
- Padrão DAO
- PreparedStatement
- ResultSet
- CRUD com MySQL
- Relacionamento entre entidades
- Tratamento de exceções de banco
- Factory para criação dos DAOs
- Maven para gerenciamento de dependências

## Tecnologias

- Java 21
- MySQL
- JDBC
- Maven
